# Новый Telegram-бот для заявок сайта

Отдельный Node.js-проект для единого клиентского Telegram-бота сайта `danisgaripov.ru`.

Этот проект не изменяет и не заменяет существующего бота `@finance_razbor_bot`. Старый бот остаётся только для проверки подписки и выдачи кода доступа к бесплатному финансовому разбору.

## Что реализовано

- Приветственное сообщение с изображением, документами и согласием на обработку персональных данных.
- Главное меню: финансовый разбор, диагностика кредитной истории, отправка документов, статус заявки, связь с командой.
- Приём пользователей после перехода с сайта через `/start` и deep-link payload.
- Выбор направления: финансовые разборы, диагностика кредитной истории, бизнес-психолог, кредитование, частные займы, возврат страховок, срочный выкуп авто, IT-разработка.
- Создание заявки с уникальным номером.
- Приём текстовых анкет, ответов, PDF-файлов, документов и скриншотов/фото.
- Передача каждой новой заявки и новых материалов в закрытую Telegram-группу администраторов.
- Администрирование прямо из закрытой группы без отдельной панели:
  - `/info REQ_ID` — посмотреть заявку;
  - `/status REQ_ID статус` — изменить статус и уведомить клиента;
  - `/reply REQ_ID текст` — отправить сообщение клиенту;
  - `/result REQ_ID текст` — отправить результат клиенту;
  - `/close REQ_ID` — закрыть заявку.
- Кнопки под заявкой в закрытой группе: `Взять в работу`, `Связались`, `Ожидаются документы`, `Завершено`.
- Команды нового бота: `/start`, `/services`, `/documents`, `/status`, `/help`.
- Файловое JSON-хранилище заявок для первого production-запуска без базы данных.
- Расширяемая структура сценариев в `src/messages.mjs`.

## Архитектура

```text
telegram-bot/
├── src/
│   ├── bot.mjs           # long polling, маршрутизация сообщений и админ-команды
│   ├── config.mjs        # переменные окружения
│   ├── messages.mjs      # сценарии услуг, статусы и тексты
│   ├── store.mjs         # файловое хранилище заявок
│   └── telegram-api.mjs  # тонкая обёртка над Telegram Bot API
├── test/
│   └── messages.test.mjs
├── .env.example
├── package.json
└── README.md
```

## Запуск

1. Создать нового бота через `@BotFather`.
2. Добавить нового бота в закрытую группу команды Даниса.
3. Узнать `ADMIN_CHAT_ID` закрытой группы.
4. Создать `.env` на основе `.env.example`.
5. Запустить:

```bash
cd telegram-bot
npm test
npm start
```

## Переменные окружения

- `CLIENT_BOT_TOKEN` — токен нового Telegram-бота. Не использовать токен `@finance_razbor_bot`.
- `ADMIN_CHAT_ID` — id закрытой группы команды.
- `PUBLIC_SITE_URL` — адрес сайта.
- `DATA_DIR` — папка для JSON-хранилища заявок.
- `POLL_TIMEOUT_SECONDS` — timeout long polling.
- `POLL_RETRY_DELAY_MS` — пауза перед повтором при ошибке Telegram API.

## Deep-link payload для будущей интеграции сайта


## Важные ограничения этапа 6

- Проверка платежей Robokassa подготовлена как серверный контур, но без боевого callback от Robokassa статус оплаты не устанавливается автоматически.
- Кнопка «Я уже оплатил» не открывает загрузку документов без серверного подтверждения оплаты.
- Хранилище файловое, без CRM/БД. При росте нагрузки `store.mjs` можно заменить адаптером базы данных без изменения команд и сценариев.

## Инструкция для команды

Новые заявки появляются в закрытой группе Telegram, указанной в `ADMIN_CHAT_ID`. Каждая заявка приходит отдельным сообщением с номером `REQ-00001`, услугой, пакетом, контактами, источником и ответами пользователя.

Как определить услугу и пакет: смотрите строки `Услуга` и `Пакет` в сообщении заявки. Для диагностики кредитной истории дополнительно проверяйте статус оплаты.

Как взять заявку в работу: нажмите кнопку `Взять в работу` под заявкой. Если заявка уже назначена другому сотруднику, бот покажет, кто с ней работает.

Как изменить статус: используйте кнопки под заявкой или команду `/status REQ-00001 in_progress`. Доступные статусы: `collecting`, `assigned`, `in_progress`, `waiting_client`, `ready`, `closed`.

Как запросить документы: установите статус `waiting_client` или напишите клиенту командой `/reply REQ-00001 текст запроса`.

Как написать пользователю: используйте `/reply REQ-00001 текст`. Для отправки результата используйте `/result REQ-00001 текст`.

Как найти старую заявку: используйте `/info REQ-00001` в закрытой группе.

Как добавить сотрудника: добавьте человека в закрытую группу Telegram. Для работы со статусами ему нужны права писать сообщения в группе.

Как удалить сотрудника: удалите человека из закрытой группы Telegram.

Какие права нужны боту: бот должен быть администратором группы и иметь доступ к сообщениям.

Если заявки перестали поступать: проверьте процесс на сервере командой `pm2 status`, затем безопасно посмотрите логи `pm2 logs danis-client-telegram-bot --lines 50 --nostream`.

Как перезапустить бота: `pm2 restart danis-client-telegram-bot --update-env`, затем `pm2 save`.

Переменные окружения без значений:

- `CLIENT_BOT_TOKEN`
- `ADMIN_CHAT_ID`
- `PUBLIC_SITE_URL`
- `DATA_DIR`
- `POLL_TIMEOUT_SECONDS`
- `POLL_RETRY_DELAY_MS`

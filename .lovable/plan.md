## Редизайн hero-блока в стиле референса

Цель: заменить нынешнее фото Даниса на новое (присланное) и оформить hero-блок в стиле референса с Кириллом Артамоновым — драматичный тёмный фон с фактурой (цепи/кристаллы/блики), крупное имя поверх фото, фигура вырезана и интегрирована в композицию. Цветовая палитра сайта (графит #1E1E1E, молочный #FDFDFD, оливково-золотистый #97965B, серо-оливковый #65653F, сливово-графитовый #2E2430) полностью сохраняется — никакого красного и серебра, как в референсе.

### 1. Подготовка фото

- Загруженное фото Даниса (поло, светлый фон) сохранить в `src/assets/danis-garipov-hero.png`, заменив текущее.
- Через `imagegen--edit_image` обработать фото: удалить белый фон (transparent PNG), оставив только фигуру. Это даст возможность «вписать» его в тёмную сцену, как на референсе.

### 2. Фоновая сцена hero-блока

- Сгенерировать через `imagegen--generate_image` фоновую текстуру в палитре сайта: тёмный графитовый фон (#1E1E1E / #2E2430) с тонкими оливково-золотистыми бликами и абстрактной фактурой (геометрические кристаллы / световые лучи / лёгкая дымка) — БЕЗ красного, БЕЗ цепей в буквальном смысле, чтобы остаться в спокойной «взрослой» эстетике сервиса.
- Сохранить в `src/assets/hero-background.jpg`.

### 3. Перестройка hero-композиции в `src/pages/Index.tsx`

Композиция по референсу:

```text
┌─────────────────────────────────────────────┐
│  ФИНАНСОВЫЙ БРОКЕР · ЭКСПЕРТ · СТРАТЕГ      │  ← тонкий капс над именем
│                                              │
│  ДАНИС     [ФОТО]     ГАРИПОВ                │  ← крупное имя, фигура в центре поверх
│                                              │
│  [короткий блок слева]   [блок справа]       │
│  Финансовый сервис,      Помогаем найти       │
│  где каждый получает     решение под          │
│  своё.                   вашу ситуацию.       │
│                                              │
│  [ОСТАВИТЬ ЗАЯВКУ]   [МОИ УСЛУГИ]            │
└─────────────────────────────────────────────┘
```

Технически:
- Секция hero становится `relative` с фоновой картинкой (`hero-background.jpg`) + затемняющий градиент-оверлей в графит.
- Имя «ДАНИС ГАРИПОВ» выводится огромным шрифтом (Playfair / текущий heading-шрифт), полупрозрачным оливково-золотистым, расположено за фигурой через `z-index`.
- Фигура Даниса (transparent PNG) — по центру, поверх имени, с мягкой тенью.
- Слоган «ФИНАНСОВАЯ ЭКОСИСТЕМА, ГДЕ КАЖДЫЙ ПОЛУЧАЕТ СВОЁ» переносится в подводку над именем (мелкий капс с разрядкой) — чтобы не дублировать большой блок имени. Подзаголовок «Помогаем найти финансовое решение…» и текущие две кнопки остаются под композицией.
- Две короткие info-плашки слева/справа от фигуры (как в референсе — «Эксперт по…» и «…с N-летним опытом»):
  - Левая: «Финансовый брокер с многолетним опытом структурирования сделок».
  - Правая: «Решения под конкретную задачу, сумму и срок».
- Кнопки оставляем существующие («Оставить заявку», «Мои услуги») — стиль не меняем, только переносим под композицию.

### 4. Адаптив

- Десктоп (≥1024px): композиция как на схеме — имя за фигурой, плашки по бокам.
- Планшет (768–1023px): плашки уходят под фигуру стопкой, имя остаётся крупным фоном.
- Мобильный (<768px): фигура сверху, имя — крупным капсом под ней (а не наложением, чтобы не было каши), плашки и кнопки стопкой. Фон сохраняется.

### 5. Что НЕ меняется

- Палитра сайта (графит/молочный/оливково-золотистый/сливово-графитовый).
- Все остальные секции (Почему мне доверяют, Шаги, Финансовый разбор, Услуги, Кому подходит, Агенты, Благотворительность).
- Шрифты, кнопки, общая типографика.
- Никакого красного, серебристого металла или цепей из референса — берём только композиционную идею (крупное имя + вырезанная фигура + драматичный тёмный фон).

### Затрагиваемые файлы

- `src/assets/danis-garipov-hero.png` — заменить на новое фото (transparent PNG).
- `src/assets/hero-background.jpg` — новый файл, фоновая сцена.
- `src/pages/Index.tsx` — переписать только hero-секцию.
- `src/index.css` / `tailwind.config.ts` — точечно, если потребуется утилита для крупного «выгорающего» имени (text-stroke / opacity); цвета не трогаем.

### Результат

Hero-блок получает «вау»-композицию в духе референса, но в строгой оливково-графитовой палитре сервиса. Фото Даниса заменено и интегрировано в сцену. Остальной сайт остаётся без изменений.
